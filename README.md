# Jewelry website demo

珠寶品牌網站的互動設計展示稿。

展示網址：https://lai-wen.github.io/demo/

## 使用說明

- 靜態展示，直接由 GitHub Pages 提供 index.html。
- 商品、品牌及聯絡資料為示意內容。
- 管理介面為示範用途，修改只儲存在目前瀏覽器，不會同步到其他訪客或裝置；沒有正式登入或後端。

## 展示版回歸驗證

先用靜態伺服器提供此資料夾，再在已安裝 Playwright（Chromium 與 WebKit）的環境執行：

```sh
URL=http://127.0.0.1:32882 node scripts/check-showcase.cjs
```

覆蓋 320、393、768、899、900、1280 px 的商品圖排列、捲動遮擋、詢問彈窗、複製失敗提示、故事、關於與管理示範入口。WebKit 模擬不代表 iPhone 真機驗收。

2026-11-08：手機商品圖改為正常捲動，桌機保留黏附圖片；單雙欄切換一致；視窗高度使用 dvh；照片切換目標加大、保留鍵盤焦點提示與減少動態偏好；複製訊息不再於失敗時顯示成功。

## 載入與操作品質

展示沿用原本的米白、深色文字與珠寶攝影。載入使用小型戒指線稿動畫，內容就緒即退出，不加入最短等待；減少動態模式停用動畫。12 秒仍未就緒會顯示可重試提示，遮罩不攔截內容操作，後續載入成功仍會退場。

驗證：`URL=http://127.0.0.1:32882 node scripts/check-loading.cjs`。包含正常載入、減少動態、錯誤及等待過久後恢復。

這仍是單檔互動原型：品牌／聯絡資訊是示意，後台只存本機瀏覽器。正式框架、真正登入、多人共用資料及正式品牌內容，待方向確認後另行實作。
